# MythosAI

An offline AI assistant built with Python.

## Features

- Text-to-Text
- Text-to-Speech
- Local LLM support
- LM Studio integration

## Installation

```bash
git clone https://github.com/Ritik-015/MythosAI.git
cd MythosAI
pip install -r requirements.txt
```

Create a `.env` file based on `.env.example`.

Run:

```bash
python app.py
```
